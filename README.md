# ☁️ Cloud Expense Tracker

A simple and responsive web-based expense tracker that helps users manage their income, expenses, and balance. The project demonstrates the basic concept of cloud-based financial data management.

## 🚀 Features

* 💰 Add income
* 💸 Add expenses
* 📊 Automatically calculate balance
* 📋 View transaction history
* 🗑️ Delete transactions
* 📱 Responsive design
* ☁️ Designed for cloud database integration

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Firebase Cloud Firestore *(for future cloud integration)*
* Git & GitHub

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/jyoshithaaddanki/Cloud-Expense-Tracker.git
```

2. Open the project folder in VS Code.

3. Open `index.html` using **Live Server**.

4. Add your income and expenses.

5. The application automatically displays the total income, expenses, and balance.

## 💡 How It Works

The application uses JavaScript to store transactions and calculate:

```text
Balance = Total Income - Total Expenses
```

Users can add transactions, view their transaction history, and delete transactions.

## ☁️ Cloud Computing Concept

The project can be connected to **Firebase Cloud Firestore** to store transaction data remotely. This allows data to be accessed from different devices and demonstrates the use of cloud-based database services.
